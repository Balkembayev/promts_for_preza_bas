# promts_for_preza_bas

Готовые промты для команды Департамента Big Data — берите и используйте в работе.

## Содержание

- [🎬 Промт для 3D-анимации](./3d-animation-prompt.md) — оживление изображений в видео (Kling AI, Runway, Luma)
- [📊 Промт для презентаций (RU)](./presentation-prompt-ru.md) — бриф для сборки интерактивных HTML-презентаций с Claude
- [📊 Presentation Prompt (EN)](./presentation-prompt-en.md) — English version of the presentation brief

## Как пользоваться

Откройте нужный файл, скопируйте промт целиком и вставьте в начало нового чата вместе со своими материалами (изображение, тема презентации, брендбук и т.д.).
